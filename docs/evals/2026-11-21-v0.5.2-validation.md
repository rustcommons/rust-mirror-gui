# rust-mirror-gui 0.5.2 validation record

The owner authorized 0.5.2 on 2026-11-21: rust-mirror 0.6.0 plus main as it
stood. It is published through Trusted Publishing. This record covers the
release pull request before the merge. The CI runs at the PR's exact head
are listed in the pull request and in the publication record.

## Scope

- **Engine:** rust-mirror 0.6.0 (crates.io SHA-256
  `beaffa1b9467cd04bd03efe7c3f68fbc3b7d4d042c19175f0115a85ba3eb3275`, not
  yanked; tag v0.6.0 at `eaa63546`). Its engine code and event protocol 1
  are unchanged from 0.5.4.
- **Requirement:** `rust-mirror = "0.5.4"` → `rust-mirror = "0.6"` (0.6.0
  is not semver-compatible with 0.5).
- **This app's `Cargo.lock` changes:**
  - rust-mirror 0.5.4 → 0.6.0;
  - sha2 0.10.9 → 0.11.1, digest 0.10.7 → 0.11.3, block-buffer 0.10.4 →
    0.12.1, crypto-common 0.1.7 → 0.2.2, cpufeatures 0.2.17 → 0.3.1;
  - toml 0.8.23 → 1.2.2, serde_spanned 0.6.9 → 1.1.3, toml_parser 1.1.5 →
    1.1.6;
  - added: hybrid-array 0.4.15, const-oid 0.10.3, toml_writer 1.2.0;
  - removed: generic-array 0.14.7, toml_write 0.1.2, and the second copies
    of toml_datetime (0.6.11), toml_edit (0.22.27) and winnow (0.7.15);
  - rust-mirror-gui 0.5.1 → 0.5.2.

  477 → 475 locked packages. Unchanged: rustls 0.23.46, rustls-webpki
  0.103.17, webpki-roots 1.0.12, ring 0.17.14, and rustix 1.1.6 (0.38.44
  remains, through eframe's Linux stack).
- **The breaking change:** 0.6.0's `Error::report` is `Option<toml::Value>`
  from toml 1.x. The app has no toml dependency of its own and only reads
  that field, so no source file changes.
- **Fuzz workspace:** `fuzz/Cargo.toml` names the engine directly, so its
  pin moves `=0.5.4` → `=0.6.0`, and `fuzz/Cargo.lock` is refreshed. Every
  package in the main lock is in the fuzz lock at the same version; the fuzz
  lock adds only `arbitrary`, `libfuzzer-sys` and the fuzz crate.
- `LIBRARY_VERSION` (`src/worker.rs`) is 0.6.0; a test checks it against
  the lockfile.
- No new crate dependencies.
- `trusted-publishing.yml` is unchanged.
