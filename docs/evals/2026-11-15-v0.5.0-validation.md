# rust-mirror-gui 0.5.0 validation record

0.5.0 builds its fonts in, documents the supported platforms, and records
CI-only glibc measurements. The owner approved it on 2026-11-15 and
authorized publication once green. This record covers the release pull
request (#21) before the merge.

## Built-in fonts

- **Why:** egui 0.37's built-in fonts lack ✔, ✖ and ⚠ (its emoji fonts are
  behind an epaint feature that eframe doesn't enable), and → and ● are
  covered only by its monospace font. eframe looked missing symbols up
  among the system fonts through fontconfig. On a minimal AlmaLinux 8
  without fontconfig, ✔ showed as an empty box (0.4.3 dry runs 43693863403
  and 43694860881).
- **Change (`src/fonts.rs`):**
  - DejaVu Sans 2.37 (`assets/fonts/DejaVuSans.ttf`, from the upstream
    release `dejavu-fonts-ttf-2.37.tar.bz2`) is added as the last fallback
    of the proportional and monospace families;
  - `NativeOptions::system_font_fallback` is `false`;
  - license: `NOTICE`, `assets/fonts/LICENSE-DejaVu.txt`, and
    `LICENSE-DejaVu.txt` in each download.
- **Tests:**
  - `every_symbol_the_ui_uses_has_a_glyph` scans the string literals in
    `src/` (found: · – — “ ” … → ● ⚠ ✔ ✖) and checks both families;
  - `without_the_bundled_font_the_check_mark_is_missing` guards it.
- **Size** (0.4.3's live downloads against 0.5.0's dry-run archives):

## Supported platforms

The README's new section separates "tested" from "expected":
- **Tested:**
  - every release, by the release workflow: Windows Server 2022, macOS
    (program and engine only), AlmaLinux 8 and Ubuntu 20.04;
  - by a recorded qualification: Windows Server 2025, Remote Desktop, xrdp,
    and Windows 11 on the owner's PC.
- **Expected, not tested:** Windows 10, the macOS window, RHEL and Rocky 8,
  Debian 10+, SLES 15 SP4+, Wayland.
- The tutorial, the downloads' `README.txt` and the About page link to it.

## glibc measurements

See the [glibc record](2026-11-15-glibc-experiments.md). In short:
- the published AlmaLinux 8 build needs glibc 2.28;
- a cargo-libc 2.17 build runs its engine (HTTPS plan and sync) on every
  glibc 2.17+ userland tested, but draws its window only on Debian 9;
- the Linux download stays the 2.28 build.

## Other checks

- `cargo fmt --check`, `cargo clippy --all-targets --all-features -D
  warnings` and `cargo test --all-features` (31 + 19 tests) pass, including
  the layout checks at 900×600 with 100%, 125% and 150% scaling.
- The release-documentation check passes.

## Not tested

- Wayland.
- Real GPUs on Linux.
- Old kernels.
