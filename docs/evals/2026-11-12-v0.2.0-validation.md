# rust-mirror-gui 0.2.0 validation record (2026-11-12)

Scope: the corporate-network features in 0.2.0. Development and testing used
rust-mirror 0.3.0 from its branch `feat/corporate-network-030`. The final runs
were at commit `3d86a14` (retested at the frozen qualification commit `7a00908`); earlier ones at `41948e5`. **Before publication, the
dependency must be switched to crates.io rust-mirror 0.3.0, and the automated
tests and a smoke run repeated.** That result is recorded in the 0.2.0
publication record.

Environment:
- Debian 12 aarch64, Rust 1.99.1.
- Xvfb with Mesa lavapipe, no GPU.
- Real network access to static.rust-lang.org.
- All outputs written under `/tmp`. No Rustup/Cargo homes or Nexus servers
  were touched.

## Test proxy

A local Python CONNECT proxy, used only for testing. It ran in two modes:
- plain;
- **TLS inspection:** it terminated TLS with a certificate for
  static.rust-lang.org signed by a private test CA (`CN=Test CA`) and
  re-encrypted the traffic to the real server.

It required Basic auth for user `alice`. The auth scheme was matched
case-insensitively and the token exactly (RFC 9110 §11.1).

One false alarm is recorded honestly. The first harness compared
`Basic <token>` literally and rejected ureq's lowercase `basic`. I reported a
missing-credentials bug to rust-mirror. It was traced to this harness and the
report was closed; rust-mirror added a credential-required regression test
anyway.

GUI runs (window-only screenshots in `docs/screenshots/network-*.png`), using
the TLS-inspecting authenticating proxy:
- the connection test failed at TLS with "Certificate issued by CN=Test CA";
- the add-certificate flow showed details and fingerprint before use;
- the re-test passed all steps;
- release refresh and the picker worked;
- plan preview showed "about 1.5 GiB of 10.0 GiB budget (estimate)";
- the sync showed "13% · 190.6 MiB of about 1.5 GiB · 35.8 MiB/s · about 38 s
  left (estimate)" and completed.

**Secret handling:**
- After these runs, the test password appears in none of the settings file,
  the release cache, the mirror output or the proxy logs.
- Unit tests confirm it is absent from arguments, environment and the
  displayed command.
- The accessibility tree shows the password field masked.

Automated: 17 unit tests and 14 process tests pass with `--all-features`
(fake worker plus real worker).

## Not covered

- Real corporate proxies; NTLM/Kerberos (not supported); SOCKS (not supported).
- Windows and macOS runtime; Remote Desktop and machines without a GPU (see
  the roadmap); screen readers.
- Publishing through a proxy. Publish keeps its 0.1.0 networking.
