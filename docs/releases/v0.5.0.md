# rust-mirror-gui 0.5.0: built-in fonts, documented supported platforms

Released 2026-11-15. A minor release. The app now carries its own font, so
symbols such as ✔ draw on every system, even one without fonts. Where the
GUI runs, what is tested and what isn't supported are now written down.

## Changes

- **Fonts are built in.** egui's own fonts lack some symbols the app shows
  (✔, ✖, ⚠, ●, →). Until now eframe looked them up among the system fonts,
  which on Linux needs fontconfig and an installed font; on minimal systems
  the symbols showed as empty boxes.
  - 0.5.0 bundles DejaVu Sans 2.37, after egui's fonts, and no longer looks
    up system fonts at all.
  - A test checks that every non-ASCII character in the app's text has a
    glyph.
  - fontconfig and DejaVu are no longer in the documented Linux runtime
    packages.
  - The font's free license is in `NOTICE`, in the crate, and in each
    download as `LICENSE-DejaVu.txt`.
- **Supported platforms** are documented in the README, the tutorial, the
  downloads' `README.txt` and the About page:
  - **Supported:** Windows x64, macOS 11 or newer, and x86-64 Linux with
    glibc 2.28 or newer, on a GPU or software rendering. The README
    separates "tested" from "expected to work, not tested".
  - **Not supported:** older Linux (RHEL/CentOS 7, Ubuntu 16.04 and 18.04,
    Debian 9, SLES 12), 32-bit systems, ARM Linux and Windows on ARM. Use
    the [rust-mirror command line](https://github.com/rustcommons/rust-mirror)
    there.
  - **Known limits:** listed in the README.
- **How old a Linux can the GUI run on?** This was measured in CI only;
  nothing was published.
  - Builds made with cargo-libc for glibc 2.17 load on every glibc 2.17+
    system tested, and their engine syncs crates over HTTPS there.
  - The window, however, drew only on Debian 9: on CentOS 7, Ubuntu
    16.04/18.04, Debian 8 and openSUSE 42.3, the old X (libxcb) or Mesa
    libraries stop it.
  - The Linux download therefore stays the glibc 2.28 build. See the
    [record](https://github.com/rustcommons/rust-mirror-gui/blob/main/docs/evals/2026-11-15-glibc-experiments.md).

## Upgrade

Download the archive for your system from the
[GitHub Release](https://github.com/rustcommons/rust-mirror-gui/releases/tag/v0.5.0),
or:

```sh
cargo install rust-mirror-gui --version 0.5.0 --locked
```

- **The downloads are not code-signed.** Check the archive against
  `SHA256SUMS`, and optionally its provenance with
  `gh attestation verify <archive> --repo rustcommons/rust-mirror-gui`.
  Windows SmartScreen and macOS Gatekeeper ask before the first run; the
  README says what to do.
- **Size:** the program is about 0.76 MB larger (the font), and each
  download about 0.39 MB larger.
- **Linux:** the runtime packages are the same minus fontconfig and DejaVu.
  Leaving them installed does no harm.
- Rust 1.95 or newer is still required to build from source. The built-in
  engine is still rust-mirror 0.5.1. Catalogs, mirrors and settings are
  unchanged.
- No new crate dependencies. The font is a bundled file, approved by the
  owner.

## Validation and limits

Evidence is in the
[0.5.0 validation record](https://github.com/rustcommons/rust-mirror-gui/blob/main/docs/evals/2026-11-15-v0.5.0-validation.md)
and the
[glibc measurements](https://github.com/rustcommons/rust-mirror-gui/blob/main/docs/evals/2026-11-15-glibc-experiments.md).

- **Release-workflow dry run** of this release's source, on all four
  targets: build, `--worker --version`, packaging and checksums.
  - **Windows:** a PrintWindow capture.
  - **Linux:** AlmaLinux 8 and Ubuntu 20.04, launched with every system
    font and the fontconfig settings deleted first. The window drew, with ✔
    from the built-in font.
- **Tests:** unit tests check the glyph coverage, and that egui's own fonts
  really lack ✔. The layout checks still pass at 900×600 with 100%, 125%
  and 150% scaling.
- **Known limits** (also in the README):
  - On AMD EPYC machines without a GPU, the window uses about 66% of one
    core while a download runs.
  - Screen readers are not tested.
  - The downloads are not code-signed.
  - The macOS window and Wayland are not tested.
  - Old kernels are not tested: containers share the CI runner's kernel.
