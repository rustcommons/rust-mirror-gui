# rust-mirror-gui 0.5.1: verifiable downloads, rust-mirror 0.5.4

Released 2026-11-16. A patch release. The app itself works as in 0.5.0. What
changes is how the release is made and how you can check it:
- the downloads come with an SBOM and SLSA Build Level 3 provenance;
- two independent builds give byte-identical files;
- the crate is published to crates.io by Trusted Publishing.

The built-in engine is rust-mirror 0.5.4.

## Changes

- **Built on rust-mirror 0.5.4.** It has the same engine code as 0.5.3, and
  picks up its patched dependency lineage: rustls 0.23.46, rustls-webpki
  0.103.17 (was 0.103.16) and rustix 1.1.6. cargo-deny reports no
  advisories for the release's dependencies.
- **An SBOM for every release:** `rust-mirror-gui-0.5.1.cdx.json`
  (CycloneDX 1.6) lists every dependency built into the program, for all
  four targets. It is listed in `SHA256SUMS`, and each archive carries a
  signed attestation binding it to this SBOM.
- **SLSA Build Level 3 provenance:** the release build runs in a reusable
  workflow (`build-binaries.yml`). It signs the attestations itself,
  isolated from the workflow that triggered it, as GitHub describes for
  SLSA v1 Build Level 3. The release checks verify:
  - the signer workflow;
  - that the source and signer are the release commit;
  - that the build ran on GitHub-hosted runners;
  - that the attested SBOM is the published file.
- **Reproducible builds:** building the same commit twice on fresh runners
  gives byte-identical executables and archives for all four targets. The
  Windows build now links with `/Brepro`, so the linker writes content hashes
  instead of timestamps.
- **Trusted Publishing:** the crate is published from the release tag by
  `trusted-publishing.yml`, with a short-lived token and the owner's
  approval. No crates.io API token exists any more.
- **Security baseline for the repository:**
  - every GitHub Action is pinned to a commit;
  - workflow security lint (zizmor) runs on every change;
  - dependency policy (cargo-deny): advisories, an allowed-license list,
    crates.io only;
  - OpenSSF Scorecard;
  - monthly Dependabot updates.

## Upgrade

Download the archive for your system from the
[GitHub Release](https://github.com/rustcommons/rust-mirror-gui/releases/tag/v0.5.1),
or:

```sh
cargo install rust-mirror-gui --version 0.5.1 --locked
```

**Check a download:**
- compare it with `SHA256SUMS`;
- verify its provenance:

  ```sh
  gh attestation verify rust-mirror-gui-0.5.1-<target>.<zip|tar.gz> \
    --repo rustcommons/rust-mirror-gui \
    --signer-workflow rustcommons/rust-mirror-gui/.github/workflows/build-binaries.yml
  ```

- add `--predicate-type https://cyclonedx.org/bom` to check its SBOM
  attestation.

Notes:
- **Not code-signed:** Windows SmartScreen and macOS Gatekeeper still ask
  before the first run; the README says what to do.
- **Earlier releases:** 0.4.3 and 0.5.0 have no SBOM, and their provenance
  names `release-binaries.yml` as the signer.
- **Nothing else changes:** platforms, runtime packages, catalogs, mirrors
  and settings are as in 0.5.0. Rust 1.95 or newer is still required to
  build from source.
- **Dependencies:** no new crate dependencies; only rust-mirror and the
  locked versions above change.

## Validation and limits

Evidence is in the
[0.5.1 validation record](https://github.com/rustcommons/rust-mirror-gui/blob/main/docs/evals/2026-11-16-v0.5.1-validation.md)
and the
[reproducibility record](https://github.com/rustcommons/rust-mirror-gui/blob/main/docs/evals/2026-11-15-reproducible-builds.md).

- **Release-workflow dry run** of this release's exact source, on all four
  targets: build, `--worker --version`, packaging, SBOM and `SHA256SUMS`.
  - **Windows:** the window was captured with PrintWindow.
  - **Linux:** the window was launched in AlmaLinux 8 and Ubuntu 20.04 with
    every system font removed.
- **Reproducibility check** of this release's exact source: two independent
  builds of each target, compared byte for byte.
- **Tests:** unit and integration tests, and cargo-deny.
- **Known limits:** unchanged from
  [0.5.0](https://github.com/rustcommons/rust-mirror-gui/blob/main/docs/releases/v0.5.0.md#validation-and-limits):
  - on AMD EPYC machines without a GPU, the window uses about 66% of one
    core during downloads;
  - screen readers, the macOS window and Wayland are not tested;
  - the downloads are not code-signed;
  - reproducibility is shown on GitHub's pinned runner images, not across
    different toolchains or machines.
